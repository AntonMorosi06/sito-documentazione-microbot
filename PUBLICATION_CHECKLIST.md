# Publication Checklist

This checklist defines the review process for `sito-documentazione-microbot`.

Because this repository is public, the checklist should be treated as mandatory before adding or expanding public content.

## Current Publication Status

```text
public documentation site / publication-review-required
```

This repository is already public, so the priority is not only future publication. The priority is public safety, clarity and review discipline for everything already present and everything added later.

## Core Publication Rule

Do not add public content unless it is:

1. relevant to MicroBot;
2. safe to publish;
3. free of private information;
4. not redistributing restricted external material;
5. clearly labeled by maturity level;
6. consistent with MicroBot claim boundaries.

## Content Redistribution Checklist

| Done | Requirement |
|---|---|
| [ ] | External references are cited or linked, not blindly redistributed. |
| [ ] | Books, papers and third-party sources are not uploaded as full binary files unless redistribution is allowed. |
| [ ] | Generated catalogs or inventories do not expose private paths or sensitive names. |
| [ ] | PDF/project materials are reviewed before public linking. |
| [ ] | Bibliography pages distinguish references from redistributed content. |

## Public Readiness Checklist

This repository can be treated as a stronger public documentation site when:

- [ ] status and limitation files are linked from README;
- [ ] public navigation exists;
- [ ] privacy review passes;
- [ ] content redistribution review passes;
- [ ] claim review passes;
- [ ] the homepage/landing page is readable and not overloaded;
- [ ] heavy/raw archive material is not presented as the first thing a viewer sees.

## Suggested Public Status After Review

If review passes later:

```text

```

Until then:

```text

```

## Final Rule

A public documentation site should clarify the project, not expose everything.

The safest public documentation is selected, reviewed, navigable and honest.
