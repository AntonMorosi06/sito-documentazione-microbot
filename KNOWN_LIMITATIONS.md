# Known Limitations

This document defines the limitations of `sito-documentazione-microbot`.

Because this repository is public, the limitations are especially important.

## Main Limitation

This repository is a public documentation site.

It is not a hardware evidence repository, not a firmware validation repository, not a complete internal archive and not proof that the final MicroBot system is physically complete.

## Public Content Limitation

Every public file should be reviewed before publication.

This includes:

- PDFs;
- images;
- videos;
- CSV inventories;
- generated pages;
- screenshots;
- copied notes;
- references;
- logs;
- datasets;
- code snippets;
- external bibliography notes.

## Privacy Limitation

Do not publish private material without review.

Potentially sensitive material includes:

- personal notes;
- personal documents;
- private photos;
- certificates;
- serial numbers;
- tokens or credentials;
- private logs;
- private screenshots;
- unrevised evidence folders;
- files copied from large internal archives.

## Content Redistribution Limitation

The documentation site may describe, summarize or cite references.

It should not blindly redistribute external copyrighted material, books, papers or binary files unless redistribution is clearly allowed.

Safe approach:

```text
summarize, cite, link or describe
```

Risky approach:

```text
upload and redistribute full external sources without review
```

## Claim Limitation

This repository must not overstate the maturity of MicroBot.

Safe wording:

```text
public documentation site
project documentation layer
selected MicroBot summaries
navigation for the MicroBot ecosystem
hardware-readiness path
simulation and web-demo references
```

Unsafe wording:

```text
validated physical swarm
production robot platform
real hardware telemetry proven by this site
complete public archive of all MicroBot material
```

## Hardware Limitation

This repository does not validate hardware.

Hardware evidence belongs in repositories such as:

```text
microbot-labs
primoPrototipo
microbot-drone-physical-lab
```

This documentation site may link to hardware evidence after it is reviewed, but it should not replace the evidence repository.

## Simulation Limitation

Simulation references should remain clearly labeled as simulation.

Simulation output is not physical proof.

Related repository:

```text
Microbot-Simulation-Core
```

## Web Demo Limitation

Dashboard or web demo pages should not be described as real hardware dashboards unless real evidence exists.

Related repository:

```text
MICROBOT-ULTRA-WEBSITE
```

## Documentation Scope Limitation

This site should not try to publish everything.

A public documentation site should prioritize:

- readable summaries;
- project map;
- selected diagrams;
- safe references;
- public-safe roadmap;
- links to related repositories;
- status boundaries.

It should avoid becoming a raw dump of internal archives.

## Final Limitation Statement

`sito-documentazione-microbot` should make MicroBot easier to understand publicly. It should not expose private material, redistribute unreviewed external content or present planned/simulated work as validated physical evidence.
