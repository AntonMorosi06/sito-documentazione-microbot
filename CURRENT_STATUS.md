# Current Status

Project: `sito-documentazione-microbot`

This repository is the public/static documentation site for the MicroBot ecosystem.

It is intended to provide a readable entry point for selected MicroBot documentation, project summaries, navigation paths, references and public-facing explanations.

## What This Repository Can Claim

It is accurate to say that this repository:

- provides a public documentation layer for MicroBot;
- can organize selected project summaries and navigation pages;
- can help visitors understand the MicroBot ecosystem;
- can link to related MicroBot repositories;
- can explain which parts are documentation, simulation, web demo, hardware-readiness or future evidence.

## What This Repository Must Not Claim

It must not claim that it proves:

- a completed physical MicroBot swarm;
- hardware validation;
- validated magnetic docking;
- real drone-MicroBot integration;
- real BCI control;
- production readiness;
- complete public release of all internal project material.

## Current Main Strength

The main strength of this repository is visibility.

It can become the place where an external viewer first understands MicroBot without needing to open every technical repository.

## Current Main Risk

The main risk is public exposure.

Because this repository is public, every included file, reference, PDF, inventory, image, log or generated page must be reviewed for privacy, redistribution safety and claim accuracy.

## Recommended Next Milestone

```text
v0.1 — Public Documentation Control Baseline
```

This milestone should add status, limitations, publication checklist, documentation navigation and README links before expanding the site further.

## Final Status Statement

`sito-documentazione-microbot` is a public MicroBot documentation site that needs a stronger review and navigation layer before it should be treated as a polished public documentation portal.
